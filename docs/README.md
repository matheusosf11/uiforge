# Docs assets

- `screenshot-light.png` and `screenshot-dark.png` are generated by Playwright against the production build with the mock model (no API key, no real data). Regenerate with:

  ```bash
  SCREENSHOTS=1 npx playwright test e2e/screenshots.spec.ts
  ```

  (PowerShell: `$env:SCREENSHOTS="1"; npx playwright test e2e/screenshots.spec.ts`)

- `demo.gif` is a placeholder. After deploying, the owner records a short GIF (prompt -> streaming -> preview) and saves it here as `docs/demo.gif`.
