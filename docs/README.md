# Docs assets

Both assets are generated by Playwright against the production build with the mock model (`UIFORGE_E2E_MOCK=1`: no API key, no real data). The site is dark-only, so there is no light screenshot.

- `screenshot-dark.png`: README screenshot (1280x800 viewport). Regenerate with:

  ```bash
  SCREENSHOTS=1 npx playwright test e2e/screenshots.spec.ts
  ```

  (PowerShell: `$env:SCREENSHOTS="1"; npx playwright test e2e/screenshots.spec.ts`)

- `demo.gif`: the demo (type a prompt, generate, refine with a suggestion chip, undo, edit the code by hand with the preview updating). Recorded at 1600x900 by `e2e/demo.spec.ts` (gated by `DEMO=1`) and converted to about 960px wide, sped up 1.35x, capped at 25 s, with the faint animated background lines flattened to keep it at most 3 MB. Regenerate with:

  ```bash
  npm run demo:gif
  ```

  This requires `ffmpeg` on PATH (not a project dependency; Windows: `winget install Gyan.FFmpeg`). `npm run demo:gif -- --convert-only` reconverts the last recording (`test-results/demo/demo.webm`) without recording again. Set `E2E_PORT` if port 3100 is taken.
