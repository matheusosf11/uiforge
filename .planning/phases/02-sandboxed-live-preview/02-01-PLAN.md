<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Host React tree → Sandpack iframe | Untrusted LLM TSX crosses here. Must enter only as a Sandpack `files` string, never as host-evaluated JSX. |
| layout.tsx → document CSS | `getSandpackCssText()` is library CSS (trusted). Distinct from generated HTML. |
| GeneratorShell → /api/generate | Unchanged Phase 1 hop. Preview consumes `parseCode(completion)` after the stream ends. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Elevation of Privilege / Tampering | Generated TSX on host origin | mitigate | Execute only inside Sandpack iframe via `files={buildSandpackFiles(code)}`. Ban `eval(`, `new Function(`, and `dangerouslySetInnerHTML` of `parsed`/`completion`/`previewCode`. Grep-asserted in Tasks 2–3. |
| T-02-02 | Information Disclosure | Generated code vs host cookies/localStorage | mitigate | Do not weaken Sandpack iframe sandbox. Do not render generated components with host React. Gemini key stays server-only (unchanged). |
| T-02-03 | Tampering | `SandpackCss` `dangerouslySetInnerHTML` | mitigate | Payload is solely `getSandpackCssText()` (stitches library CSS). Never interpolate model output into that style tag. |
| T-02-04 | Denial of Service | Sandpack remount per token | mitigate | Snapshot `previewCode` on `isLoading` false only; Sandpack absent from the tree while `isLoading`. `key={code}` resets bundler per finished generation, not per token. |
| T-02-05 | Spoofing | RSC `ssr: false` misuse | mitigate | `next/dynamic(..., { ssr: false })` only in `generator-shell.tsx`. `page.tsx` remains an RSC host with no `dynamic` import. |
</threat_model>
