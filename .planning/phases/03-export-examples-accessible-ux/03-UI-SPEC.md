# Phase 3 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Baseline: Phase 2 UI-SPEC + existing tokens in `src/app/globals.css`. This phase **overrides** the Phase 2 mobile stack with Preview ⇄ Código tabs (CONTEXT D-12).
> Language: all user-facing copy is Brazilian Portuguese (pt-BR).

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn (`components.json` present) |
| Preset | `base-nova`, baseColor `neutral`, CSS variables, Tailwind v4 CSS-first (no `tailwind.config.*`) |
| Component library | `@base-ui/react` (shadcn base-nova); only local `Button` / `buttonVariants` and `Textarea` exist — no new shadcn components added this phase |
| Icon library | `lucide-react` (`Copy`, `Check`, `Download`, `Sun`, `Moon`, `RotateCcw`) |
| Font | Geist Sans (`--font-sans`) for UI; Geist Mono (`--font-geist-mono`) for code |
| Theme engine | `next-themes` 0.4.6, `attribute="class"`, `defaultTheme="dark"`, `enableSystem={false}`, `disableTransitionOnChange` |

No new dependencies. No Tabs/Toast/Tooltip library: tabs are a hand-rolled `role="tablist"`, feedback is in-button text (never a toast).

## Spacing Scale

Declared values (multiples of 4; Tailwind 4px unit):

| Token | Value | Tailwind | Usage |
|-------|-------|----------|-------|
| xs | 4px | `gap-1`, `p-1` | Icon-to-label gap inside buttons (`gap-1` from `size="sm"`), tablist track inner padding |
| sm | 8px | `gap-2`, `mb-2`, `py-2` | Chip-to-chip gap, Copiar↔Baixar gap, panel title → content, alert vertical padding |
| md | 16px | `p-4`, `gap-4` | Panel padding (all cards), grid gap between columns |
| lg | 24px | `p-6`, `gap-6` | Page padding (mobile), header → shell gap |
| xl | 32px | `md:p-8` | Page padding (desktop) |
| 2xl | 48px | — | Not used this phase |
| 3xl | 64px | `min-h-64` = 256px (16×16) | Minimum panel height (Preview, Code, Prompt) |

Exceptions:
- 12px (`gap-3`, `px-3`, `mt-3`): right-column stack gap (status → alert → tabs → panels), alert horizontal padding, textarea → chips gap and chips → Gerar row gap. Multiple of 4, kept from existing code.
- Mobile tab buttons: `h-11` (44px) touch target.
- Chips, Copiar, Baixar, Tentar de novo: `size="sm"` = 28px height (`h-7`). Accepted below 44px because they are secondary, spaced 8px apart, and on desktop pointer-first; do not shrink further.
- Theme toggle: `size="icon"` = 32px square (`size-8`).

## Color

Values come from existing `globals.css` (shadcn neutral). Hex is the sRGB equivalent of the OKLCH token.

| Role | Token | Dark (default) | Light | Usage |
|------|-------|----------------|-------|-------|
| Dominant (60%) | `--background` | `#0a0a0a` | `#ffffff` | Page background |
| Secondary (30%) | `--card`, `--muted` | `#171717` / `#262626` | `#ffffff` / `#f5f5f5` | Panels (Prompt, Preview, Código gerado), tablist track (`bg-muted`), empty/loading placeholders (`bg-muted/30`, dashed border) |
| Accent (10%) | `--primary` | `#e5e5e5` (fg `#171717`) | `#171717` (fg `#fafafa`) | See reserved list below |
| Destructive | `--destructive` | `#ff6467` | `#e7000b` | Error alerts only (`border-destructive/40 bg-destructive/10 text-destructive`) |
| Border / ring | `--border`, `--ring` | `rgba(255,255,255,0.10)` / `#737373` | `#e5e5e5` / `#a1a1a1` | Panel borders, chip outlines, focus ring (`ring-ring/50`, 3px) |

Accent (`bg-primary text-primary-foreground`) reserved for exactly:
1. Gerar submit button (existing default variant).
2. The currently selected example chip (`aria-pressed="true"`).

Not accent: active mobile tab (uses `bg-background text-foreground shadow-sm` on `bg-muted` track), Copiar/Baixar/Tentar de novo (outline), theme toggle (ghost), Parar (secondary).

Preview canvas exception (D-10): the iframe body stays white (`bg-white`) in both host themes. It is a product surface, not a host token. Iframe document must set `color-scheme: light dark` so host `color-scheme` does not leak into `prefers-color-scheme` inside the iframe.

Code highlighting (D-11): `prism-react-renderer` `themes.nightOwl` when resolved theme is dark, `themes.nightOwlLight` when light. First render always `nightOwl`; switch after mount (avoids hydration mismatch).

## Layout & Interaction Contract

### Header (`src/app/page.tsx`, stays a Server Component)
- Row: `flex items-center justify-between gap-3` → `h1` “UIForge” left, `<ThemeToggle />` right. Subtitle `p` (text-sm, muted) below the row, unchanged copy.
- ThemeToggle: `Button variant="ghost" size="icon"`, icon 16px. Dark active → `Sun` icon, `aria-label="Ativar tema claro"`. Light active → `Moon` icon, `aria-label="Ativar tema escuro"`. Before mount: same-size disabled placeholder button with `aria-hidden`, no layout shift. Stored `theme="system"` is coerced to `dark`.

### Shell grid (`GeneratorShell`)
- Desktop `md+` (≥768px): `md:grid-cols-2 gap-4`. Left column = Prompt panel (`md:order-1`). Right column = status → alert → Preview panel → Código gerado panel, stacked with `gap-3`. Tablist hidden (`md:hidden`); both panels always visible.
- Mobile (<768px): single column. Order: right-column block first (status, alert, tablist, active panel), then Prompt panel (`order-2`) — Prompt, chips and Gerar always visible below the tab panel; Prompt is never a tab.
- Both tab panels stay mounted; inactive one hidden with `max-md:hidden` (never unmounted — keeps iframe and stream alive).

### Mobile tabs
- `role="tablist" aria-label="Resultado"`, `grid grid-cols-2 gap-1 rounded-lg bg-muted p-1`.
- Each tab: `button type="button" role="tab"`, `h-11`, `rounded-md text-sm font-medium`. Selected: `bg-background text-foreground shadow-sm`, `aria-selected="true"`, `tabIndex=0`. Unselected: `text-muted-foreground`, `tabIndex=-1`.
- Labels exactly “Preview” and “Código”. Default tab: Preview.
- Keyboard: ArrowLeft/ArrowRight move selection and focus between tabs (roving tabindex, wraps). Focus is not moved into the panel. Visible focus ring `focus-visible:ring-3 ring-ring/50`.
- Panels: `role="tabpanel"`, `aria-labelledby` the tab id; on `md+` tab roles are visually irrelevant but markup stays.

### Example chips (inside `PromptForm`, below textarea)
- Container: `mt-3 flex flex-wrap gap-2`. No heading.
- Each chip: `button type="button"` with `buttonVariants({ variant: "outline", size: "sm" })` + `text-xs`. Visible label = short label; `title` = full prompt; `aria-label="{Label}: {prompt}"`; `aria-pressed` reflects selection.
- Selected: `bg-primary text-primary-foreground border-transparent`. One chip selected at most.
- Click fills the textarea only (no submit). Selection clears when the textarea value is edited away from the chip prompt, and when Gerar runs.
- Disabled (`disabled`, 50% opacity) while generation is in flight.
- Order and content locked (D-04): Botão, Card, Badge, Input, Toggle, Navbar, Modal, Empty, Pricing, Avatar, Alert, Tabs.
- Gerar / Parar row: `mt-3 flex items-center gap-2`, after the chips.

### Código gerado panel header
- `flex items-center justify-between gap-2 mb-2`: `h2` “Código gerado” left; action group `flex gap-2` right with Copiar then Baixar.
- Both `Button variant="outline" size="sm"` + `text-xs`, icon (14px) + visible label.
- Disabled when parsed code is empty or while streaming/busy; enabled only after a generation finishes with code.
- Copiar states: idle `Copy` + “Copiar” → success `Check` + “Copiado” for 2000ms then reverts → failure `Copy` + “Não foi possível copiar”, persists until next click, and the `<pre>` contents are selected programmatically so Ctrl+C works.
- Baixar: `Download` + “Baixar”. Downloads `{ComponentName}.tsx` from `export default function|class Name` or `export default Name;` (capitalized); else `Component.tsx`. No state change on the button.

### Status & errors (right column, above tablist)
- Status line: `<p aria-live="polite" aria-atomic="true" class="text-sm text-muted-foreground">`, always mounted (empty string when idle). Text: “Gerando…” while busy; “Pronto” after a successful finish; empty after Parar or on error. Never contains streamed tokens. The `<pre>` is not a live region.
- In-panel placeholders (“Gerando preview…”, empty states) carry no `aria-live` (no double announcement).
- Error block: `rounded-lg border border-destructive/40 bg-destructive/10 px-3 py-2 flex flex-wrap items-center justify-between gap-2`. Inside: `<p role="alert" class="text-sm text-destructive">` with message only; sibling `Button variant="outline" size="sm" text-xs` with `RotateCcw` icon + “Tentar de novo”, outside the alert node.
- Tentar de novo re-sends the last submitted prompt immediately (not the current textarea content if edited). Disabled while busy.
- Focus is never moved to the alert or the retry button.
- Raw `error.message` is never shown; only the two locked strings.
- Parar is not an error: no alert, no “Pronto”, UI returns to ready.

### States matrix

| State | Status line | Preview panel | Código gerado | Copiar/Baixar | Chips/Textarea |
|-------|-------------|---------------|---------------|---------------|----------------|
| Empty (first load) | “” | dashed placeholder, empty copy | dashed placeholder, empty copy | disabled | enabled |
| Streaming | “Gerando…” | dashed, “Gerando preview…” | tokens streaming | disabled | disabled |
| Ready | “Pronto” | sandboxed iframe (white) | highlighted code | enabled | enabled |
| Error (429/other) | “” | previous preview or empty | previous/partial code | enabled only if code exists | enabled |
| Stopped | “” | previous preview or placeholder | partial code | enabled if code exists | enabled |

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Gerar |
| Secondary CTA (in flight) | Parar |
| Textarea placeholder | Descreva um componente de UI… (⌘/Ctrl+Enter para gerar) |
| Example chips | Labels/prompts exactly as CONTEXT D-04 (e.g. “Botão” → “botão primário com ícone”) |
| Copy action | Copiar → Copiado (2s) / Não foi possível copiar |
| Download action | Baixar (file `{ComponentName}.tsx` or `Component.tsx`) |
| Theme toggle aria-label | Ativar tema claro / Ativar tema escuro |
| Tabs | Preview / Código (tablist aria-label “Resultado”) |
| Status (aria-live) | Gerando… / Pronto |
| Empty state — Preview | O preview aparece aqui depois de gerar. |
| Empty state — Código | O código gerado aparecerá aqui. |
| Loading — Preview | Gerando preview… |
| Error — rate limit (429) | Muitas tentativas. Espere um pouco e tente de novo. |
| Error — other failure | Falha ao gerar o componente. Tente novamente. |
| Retry action | Tentar de novo |
| Preview errors (unchanged from Phase 2) | O código gerado não exporta um componente padrão. / runtime message from iframe |
| Destructive confirmation | None — this phase has no destructive actions |
