<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| texto do modelo -> nome de arquivo | codigo gerado (nao confiavel) alimenta `download` |
| texto do modelo -> clipboard/Blob | TSX nao confiavel sai do host como texto puro |
| chip -> textarea | constantes estaticas, nao entrada livre |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | `componentFilename` (path traversal no nome do download) | mitigate | Nome so sai de identificador JS `[A-Za-z_$][\w$]*` + sufixo fixo `.tsx`; teste afirma o padrao do resultado |
| T-03-02 | Tampering | Copiar/Baixar do codigo gerado (XSS no host) | mitigate | Somente `writeText` e `Blob` text/plain; sem `dangerouslySetInnerHTML`, sem executar o codigo; iframe nao participa |
| T-03-03 | Information disclosure | Fallback de copia | accept | Selecao do `<pre>` visivel; nenhum dado novo exposto, codigo ja esta na tela |
| T-03-04 | Spoofing | Chips enviando prompt sem consentimento | mitigate | `type="button"`, click so preenche (D-02); teste afirma que onSubmit nao e chamado |
</threat_model>
