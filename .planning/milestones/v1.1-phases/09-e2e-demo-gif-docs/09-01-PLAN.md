- After undo with a later version: notice "Refinar a partir da v1 — v2 será descartada"
- Refine failure alert (role alert, first) contains "Sua versão anterior foi mantida"; the field keeps the failed instruction

src/lib/ai/mock-model.ts: fresh prompt -> FixtureCard; any request with currentCode -> REFINED_COMPONENT ("Refinado"); if currentCode includes "__edited__" the refined output also contains a visible "EditedSeen" paragraph; a prompt containing "__e2e_error__" fails mid-stream.

src/lib/session.ts (numbering facts): UNDO only moves the cursor (v2 survives, dimmed). COMMIT_MANUAL appends to versions.slice(0, cursor + 1), so committing the manual edit while on v1 discards v2: the manual edit becomes v2 and the refined result becomes v3. D-01 in CONTEXT wrote "v3 then v4"; that numbering assumed no truncation. The real reducer truncates (Phase 7 rule: refining from an earlier version discards later ones), so the journey asserts the real numbers: "Edição salva como v2" then "Pronto — v3". The D-01 intent (an "Edição manual" version recorded first, then the refined version, with currentCode containing the edit) is kept unchanged.
