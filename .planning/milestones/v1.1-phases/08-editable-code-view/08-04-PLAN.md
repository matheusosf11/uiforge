SandboxPreview gets code={previewCode}, updating={!!pending} unchanged (no badge for drafts), errorSource={dirty || committed.source === "manual" ? "user" : "ai"}, and onRegenerate only when !error && session.canRegenerate && !dirty (D-12; keep the WR-01 comment and extend it).
(f) CodeView gets code={editorValue}, busy={busy}, scrollResetKey (composite, see below), onChange={handleEditorChange}, readOnly={busy || !committed} (D-05), dirty={dirty}, onDiscard={() => setDraft(null)} (D-13, no confirmation), historyKey={versionKey} where versionKey = pending ? `p${pending.id}` : committed ? `${committed.id}:${state.nextVersionId}:${state.cursor}` : null.
