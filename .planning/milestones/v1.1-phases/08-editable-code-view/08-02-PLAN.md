Current CodeView({ code, busy = false, scrollResetKey = null }): useTheme -> prismTheme (nightOwlLight only when mounted && resolvedTheme === "light", else nightOwl); preRef scroll reset in useLayoutEffect on scrollResetKey; disabled = busy || !code.trim(); handleCopy (clipboard, fallback selects the pre); handleDownload (Blob + componentFilename(code)); section aria-label="Generated code"; h2 "Código gerado"; placeholder p "O código gerado aparecerá aqui." when code is empty.

New CodeView contract (later plans rely on these exact names):
  code: string                       // value shown (draft, version or streaming code)
  busy?: boolean                     // disables Copiar/Baixar (unchanged rule)
  scrollResetKey?: string | number | null // a change to a new non-null value resets the scroll wrapper (widened for the shell's composite string key)
  onChange?: (code: string) => void  // user edits
  readOnly?: boolean                 // default: busy || !onChange
  dirty?: boolean                    // shows "Editado" + "Descartar edições"
  onDiscard?: () => void
  historyKey?: string | number | null // any change resets the editor's undo stack (the shell passes a composite key that changes on every commit/navigation)

Library API (react-simple-code-editor 0.14.1, default export Editor, forwardRef): props value, onValueChange, highlight(code) => ReactNode, padding, tabSize, insertSpaces, ignoreTabKey, readOnly, textareaId, textareaClassName, className, style, onKeyDown, onFocus, onBlur. Any other prop (aria-*, data-*) lands on the wrapper div, NOT the textarea (P2). readOnly does not stop the library's own key handling (P1). The library returns early from its keydown handler when the event is defaultPrevented. The ref exposes a `session` getter/setter: { history: { stack: [{ value, selectionStart, selectionEnd, timestamp }], offset } } (P3). The library already sets spellCheck false, autoCapitalize off, autoCorrect off, autoComplete off on the textarea.
