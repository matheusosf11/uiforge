<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| localStorage -> tema | valor `theme` armazenado e lido pelo script do next-themes |
| host -> iframe sandbox | tema do host nao deve vazar para o codigo gerado |
| codigo gerado -> iframe | executa so dentro de `sandbox="allow-scripts"` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-05 | Tampering | `localStorage.theme` com valor invalido/`system` | mitigate | `enableSystem={false}`; efeito coage `system` -> `dark`; valor so vira classe do `<html>` via next-themes |
| T-03-06 | Elevation of privilege | iframe do preview | mitigate | Nao alterar `sandbox="allow-scripts"`; nao adicionar `allow-same-origin`/`allow-downloads`; so `colorScheme` no style e meta no srcdoc |
| T-03-07 | Tampering | `postMessage` do preview | mitigate | Nao alargar o listener existente nem os tipos `uiforge-preview-*` |
| T-03-08 | Information disclosure | tema do host vazando para o preview | accept | Apenas estetico; isolado por `color-scheme: light dark` (D-10) |
</threat_model>
